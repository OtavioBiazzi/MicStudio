# MicFudiddo Studio 1.8.0

## Perfis de verdade

- Nova aba Perfis: guarda voz, efeitos, volumes e (opcional) microfone e fone; aplica com um clique.
- Atalho proprio por perfil e troca automatica quando um programa abre em primeiro plano (Discord, jogo, OBS). Botao para detectar o programa.
- Atualizar com o estado atual, exportar e importar perfis (com validacao).

## Configuracoes de audio explicadas

- Campos numerados: 1. seu microfone, 2. CABLE Input (saida da voz), 3. seu fone. Guia de primeiros passos atualizado.
