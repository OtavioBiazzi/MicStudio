# MicFudiddo Studio 2.0.0

## Abertura mais rapida

- Dispositivos de audio consultados em paralelo com a biblioteca (criacao do estado: cerca de 1,0 s para 0,3 s nos testes).
- O Electron inicia o servidor de audio antes de criar a janela; a interface confirma o servidor mais cedo.

## Organizacao interna

- TTS, clipes, importacao do YouTube/TikTok, sons online e perfis agora ficam em modulos proprios (`tts`, `clipping`, `youtube_worker`, `myinstants`, `profiles`). O `backend.py` perdeu cerca de 700 linhas. Nada muda para quem usa.
